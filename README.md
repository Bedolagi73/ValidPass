# Генератор и валидатор паролей (C#, WPF)

Генерация криптостойких паролей, проверка паролей по правилам сложности (словарь частых паролей, leetspeak-подмены, список утечек, последовательности и повторы), экспорт в CSV.

## Запуск

Нужен .NET 8 SDK, Windows.

```powershell
dotnet run --project ValidPass.App -c Release
```

Сборка: `dotnet build ValidPass.sln -c Release`, exe — `ValidPass.App\bin\Release\net8.0-windows\ValidPass.exe`.

Модульных тестов в проекте пока нет. Ядро `ValidPass.Core` не зависит от WPF и файлов, поэтому тесты добавляются отдельным проектом xUnit (`dotnet new xunit -n ValidPass.Tests`), а запускаются командой `dotnet test`.

## Устройство

- `ValidPass.Core` — чистая логика:
  - `PasswordGenerator` — генерация, `IRandomProvider` / `CryptoRandomProvider`;
  - `PasswordValidator` — запускает правила `IPasswordRule`, считает энтропию и выносит вердикт;
  - `Rules\` — `LengthRule`, `CharsetRule`, `DictionaryRule`, `SubstitutionRule`, `LeakedPasswordRule`, `CommonPatternRule`;
  - `EntropyCalculator`, `DictionaryLoader`, `CsvExporter`, `PasswordList`;
  - `Models\` — `GenerationOptions`, `PasswordPolicy`, `RuleResult`, `ValidationResult`, `CsvRecord`;
  - `Resources\common_passwords.txt` — встроенный словарь, 1000 частых паролей (по `Pwdb_top-1000` из SecLists, MIT, плюс несколько добавленных).
- `ValidPass.App` — WPF: вкладки «Генерация» и «Валидация», статусная строка.

## Генерация

| Опция | Значения |
|---|---|
| Длина | 4–128, по умолчанию 16 |
| Количество | 1–1000 |
| Наборы | строчные, заглавные, цифры, спецсимволы (набор спецсимволов редактируется, по умолчанию `!@#$%^&*()-_=+[]{};:,.<>?/`) |
| Без неоднозначных | убирает `0 O o 1 l I \|` |
| Минимум из набора | например, «минимум 2 цифры» |

- Случайность — только `RandomNumberGenerator.GetInt32`. Он отбрасывает лишние значения вместо взятия остатка `%`, поэтому символы выпадают равновероятно. `System.Random` не используется.
- Алгоритм: сначала минимумы из каждого набора, затем остаток из общего алфавита, затем перемешивание Фишера–Йетса.
- Неверные опции (нет ни одного набора, длина вне 4–128, сумма минимумов больше длины, пустой набор спецсимволов) — понятная ошибка, генерация не выполняется.
- Двойной клик по паролю или «Копировать» — в буфер обмена.

## Валидация

| Правило | Нарушено, если | Влияние на шкалу |
|---|---|---|
| Длина | короче минимума (граница включена) или длиннее максимума | — |
| Наборы символов | нет обязательного набора | — |
| Словарь частых паролей | пароль или его основа без цифр и символов по краям есть в словаре (`Password123` → `password`) | сразу «слабый» |
| Подмены (leetspeak) | после обратной замены `@→a 4→a 3→e 1→i/l !→i 0→o $→s 5→s 7→t +→t` пароль словарный (`p@ssw0rd`, `s3cur3`, `l3tme1n`) | сразу «слабый» |
| Утечки | пароль или его SHA-1 есть в загруженном списке | сразу «слабый» |
| Последовательности и повторы | `abc`, `123`, `zyx` (3+), ряды клавиатуры `qwer`, `asdf` (4+), 3+ одинаковых подряд | на ступень ниже |

Все сравнения со словарём — после приведения к нижнему регистру. Пароль валиден, только если пройдены все правила.

## Энтропия и шкала

Энтропия = длина × log₂(размер алфавита).

- Длина — в видимых символах: эмодзи считается за один.
- Алфавит введённого пароля — сумма наборов, из которых в нём есть символы: строчные 26, заглавные 26, цифры 10, спецсимволы ASCII 32, прочие символы Unicode (кириллица, эмодзи) — 100.
- Для сгенерированных паролей алфавит — точный размер набора генерации.

| Шкала | Энтропия, бит |
|---|---|
| слабый | < 40 |
| средний | 40 – < 60 |
| сильный | 60 – < 80 |
| очень сильный | ≥ 80 |

Нижняя граница включена: ровно 40 бит — «средний». Пороги настраиваются на вкладке «Валидация».

## Словарь и список утечек

TXT, UTF-8, одна строка — один пароль или SHA-1 (40 hex). Формат Have I Been Pwned `HASH:count` тоже читается — берётся хеш.

- Загружается в `HashSet`, в нижнем регистре.
- Пустые строки и дубликаты отбрасываются, как и мусор: строки длиннее 256 символов и бинарные данные.
- Большой файл грузится в фоне с прогрессом, загрузку можно отменить.
- Пустой файл не ломает проверку: правило просто пропускается.

## CSV

```
password,length,entropyBits,strength,timestamp
NRq3<M)GeSgepJny,16,103.4,очень сильный,2026-11-16T13:05:12
```

- UTF-8 с BOM, строки через CRLF, разделитель `,` или `;` (для Excel с русской локалью).
- Поля с разделителем, кавычкой или переводом строки берутся в кавычки, кавычки удваиваются (RFC 4180).
- Числа — с точкой.
- «Маскировать» — вместо пароля маска `abc***xyz`.
- Без маски перед сохранением появляется предупреждение, что пароли попадут в файл открытым текстом.
- Пустой список не экспортируется.
- Экспортировать можно сгенерированные пароли и пароли, проверенные кнопкой «Проверить» или Enter.

## Безопасность

- Пароли хранятся только в памяти окна: не пишутся в логи, статусную строку и настройки, между запусками ничего не сохраняется.
- Открытая копия пароля в поле «Показать» стирается при скрытии.

## Замеры (Release)

- 1000 паролей длиной 20 — 10 мс.
- Проверка одного пароля по словарю — < 0.1 мс; пароля из 10 000 символов — 7 мс.
- Хи-квадрат по 100 000 символам из 70-символьного алфавита: 78.9 при критическом ≈ 96.4 (p = 0.01, 69 степеней свободы) — распределение равномерное.
